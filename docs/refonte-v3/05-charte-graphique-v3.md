# Charte graphique V3

Identite generale : plateforme scientifique claire, fiable, francaise, orientee apprentissage actif.

Palette cible :

- structure : bleu nuit `#071B4A`
- action principale : bleu vif `#155EEF`
- mathematiques : indigo `#4F46E5`
- physique-chimie : cyan/bleu labo `#0EA5E9`
- enseignement scientifique : vert `#10B981`
- vigilance : ambre `#F59E0B`
- erreur : rouge `#DC2626`
- surfaces : blanc, gris bleute tres clair, bordures `#D9E2F2`

Regles :

- ne jamais identifier une discipline par la couleur seule ;
- utiliser une icone, un libelle et un accent ;
- limiter les grands gradients ;
- eviter les faux chiffres et les prix non decides ;
- garder les cartes simples, 8 px de rayon par defaut ;
- ne pas imbriquer des cartes dans des cartes ;
- privilegier la lisibilite sur l'effet visuel.

Typographie :

- police principale sans serif moderne hebergee localement si possible ;
- taille de base 16 px minimum ;
- letter-spacing par defaut a 0 ;
- variantes DYS controlees par tokens, pas par surcharge improvisee.
