# Structures pedagogiques V3

Structure commune d'un chapitre :

1. vue d'ensemble ;
2. cours en lecons courtes ;
3. methodes et exemples ;
4. exercices progressifs ;
5. quiz ;
6. flashcards ;
7. activite interactive ou laboratoire ;
8. synthese et ressources.

Contrat commun minimal :

- id canonique ;
- discipline ;
- cycle ;
- niveau ;
- chapitre ;
- objectifs ;
- prerequis ;
- competences ;
- duree ;
- statut de publication ;
- acces ;
- SEO ;
- liens vers ressources ;
- version de schema ;
- sources officielles.

Extensions :

- mathematiques : theoremes, demonstrations, activites dynamiques ;
- physique-chimie : lois, unites, schema, protocole, mesures, laboratoire ;
- enseignement scientifique : documents, enjeux, donnees, modelisation, projet.
