Exercice 1 : Classer des transformations organiques

Pour chaque transformation, indiquer s'il s'agit principalement d'une addition, d'une élimination, d'une substitution, d'une oxydoréduction ou d'une réaction acide-base. Justifier chaque choix en une phrase.

  1. ${}_3-{}_2- + H^{-} {}_3-{}_2-O + ^{-}$
  2. ${}_2={}_2 + {}_2 {}_3-{}_2O$
  3. Un alcool primaire est transformé en acide carboxylique par un oxydant.
  4. Un alcool donne un alcène et de l'eau en milieu acide.
  5. ${}_3COO + H^{-} {}_3CO^{-} + {}_2$

Voir la correction
  1. ${}_3-{}_2- + H^{-} {}_3-{}_2-O + ^{-}$ : c'est une substitution. Le brome est remplacé par le groupe hydroxyde.
  2. ${}_2={}_2 + {}_2 {}_3-{}_2O$ : c'est une addition. Les éléments de l'eau s'ajoutent sur la double liaison.
  3. Alcool primaire vers acide carboxylique : c'est une oxydation, donc une oxydoréduction.
  4. Alcool vers alcène + eau : c'est une élimination. Une petite molécule d'eau est retirée et une liaison multiple apparaît.
  5. ${}_3COO + H^{-} {}_3CO^{-} + {}_2$ : c'est une réaction acide-base. L'acide éthanoïque cède un proton à $H^{-}$.

On veut transformer le propan-1-ol en propanoate d'éthyle. Une banque de réactions indique :

  1. Proposer une séquence réactionnelle en deux étapes.
  2. Nommer le produit intermédiaire.
  3. Écrire l'équation simplifiée de l'étape d'estérification.
  4. Expliquer pourquoi la banque de réactions est utile pour construire la stratégie.

Exercice 3 : Protection nécessaire ou non ?

Une molécule $A$ possède deux groupes caractéristiques : un groupe alcool et un groupe carbonyle. On souhaite réduire uniquement le groupe carbonyle en alcool en utilisant $Na{}_4$.

  1. Indiquer le rôle de $Na{}_4$.
  2. Dire quel groupe est transformé.
  3. Le groupe alcool initial doit-il être protégé dans ce cas ? Justifier.
  4. Proposer une situation dans laquelle une protection deviendrait nécessaire.

Voir la correction
  1. $Na{}_4$ est un réducteur. Il transforme notamment un groupe carbonyle en alcool.
  2. Le groupe transformé est le groupe carbonyle.
  3. Le groupe alcool initial n'a pas besoin d'être protégé si $Na{}_4$ ne le transforme pas dans les conditions utilisées. La réaction est donc sélective.
  4. Une protection deviendrait nécessaire si un réactif utilisé pour transformer un groupe risquait aussi de modifier l'autre groupe caractéristique.

Exercice 5 : Séquence vers une molécule odorante

L'anéthol peut être préparé en deux transformations à partir d'une molécule $A$ possédant un groupe carbonyle. Une première étape transforme le groupe carbonyle en groupe alcool. Une seconde étape forme une double liaison dans la chaîne carbonée.

  1. Identifier la nature de la première transformation.
  2. Identifier la nature de la seconde transformation.
  3. Expliquer comment reconnaître une élimination dans la seconde étape.
  4. Proposer deux informations expérimentales qui permettraient de vérifier que le produit final a été formé.

Voir la correction
  1. Transformer un carbonyle en alcool correspond à une réduction.
  2. Former une double liaison en retirant les éléments d'une petite molécule correspond à une élimination.
  3. Dans une élimination, deux atomes ou groupes quittent la molécule et une liaison multiple se forme. C'est ce qui se produit dans la chaîne carbonée.
  4. On peut utiliser une chromatographie pour comparer le produit à une référence, et une spectroscopie infrarouge ou RMN pour vérifier la présence des groupes attendus.

Exercice 6 : Protéger un groupe carbonyle

On souhaite transformer une molécule $A$ contenant un groupe nitro $-{}_2$ et un groupe carbonyle. La synthèse visée nécessite de transformer $-{}_2$ en $-{}_2$ sans réduire le groupe carbonyle. Une stratégie utilise trois étapes : protection du carbonyle, réduction du groupe nitro, déprotection.

  1. Expliquer pourquoi une protection du groupe carbonyle est utile.
  2. Donner le rôle de l'étape de déprotection.
  3. Dire si le groupe protecteur apparaît dans le produit final.
  4. Recopier et compléter la chaîne logique :
    $$A A_{} B_{} B$$

    avec le nom de l'opération au-dessus de chaque flèche.

Voir la correction
  1. La réduction du groupe nitro peut nécessiter des conditions qui risquent aussi de réduire le groupe carbonyle. La protection empêche le carbonyle de réagir.
  2. La déprotection retire le groupe protecteur et régénère le groupe carbonyle initial dans le produit final.
  3. Non. Le groupe protecteur est temporaire : il ne doit pas rester dans le produit final.
  4. La chaîne logique est :
    $$A {} A_{} {} B_{} {} B$$

Exercice 7 : Synthèse d'un acide hydroxycarboxylique

On veut oxyder un aldéhyde en acide carboxylique dans une molécule qui possède déjà un groupe alcool. L'oxydant utilisé est ${}_4^{-}$. On craint que le groupe alcool soit aussi oxydé.

  1. Identifier le groupe que l'on souhaite transformer.
  2. Identifier le groupe que l'on veut conserver.
  3. Proposer une stratégie protection--transformation--déprotection.
  4. Expliquer pourquoi une seule étape d'oxydation directe peut ne pas convenir.

Voir la correction
  1. Le groupe à transformer est l'aldéhyde, qui doit devenir un acide carboxylique.
  2. Le groupe à conserver est le groupe alcool.
  3. Stratégie : protéger le groupe alcool, oxyder l'aldéhyde en acide carboxylique, puis retirer le groupe protecteur.
  4. Une oxydation directe peut aussi oxyder l'alcool. On obtiendrait alors un produit différent de la cible, d'où l'intérêt de la protection.

Exercice 8 : Synthèse de l'aspirine

L'acide acétylsalicylique, appelé aspirine, peut être obtenu à partir d'acide salicylique et d'anhydride éthanoïque. L'acide salicylique peut lui-même être préparé à partir du phénol par une réaction de Kolbe.

  1. Proposer une séquence réactionnelle permettant de passer du phénol à l'aspirine.
  2. Dans la dernière étape, quel groupe de l'acide salicylique est modifié ?
  3. Expliquer pourquoi il est utile de vérifier expérimentalement la pureté du produit obtenu.
  4. Citer une méthode d'identification possible du produit final.

Voir la correction
  1. Une séquence possible est : phénol $$ acide salicylique par réaction de Kolbe, puis acide salicylique $$ aspirine par acétylation avec l'anhydride éthanoïque.
  2. Le groupe hydroxyde phénolique de l'acide salicylique est transformé en ester.
  3. Vérifier la pureté est nécessaire car des réactifs ou sous-produits peuvent rester après la synthèse. Un produit impur peut avoir des propriétés différentes.
  4. On peut utiliser la chromatographie sur couche mince, la température de fusion ou la spectroscopie infrarouge.

Exercice 9 : Validation par spectroscopie infrarouge

Lors d'une synthèse, un réactif alcool doit être transformé en cétone. On compare deux spectres infrarouges simplifiés.


























































































































































  1. Associer le spectre de l'alcool et celui de la cétone.
  2. Justifier avec les bandes caractéristiques : $-$ large vers $3300\ ^{-1}$ et $=$ vers $1700\ ^{-1}$.
  3. Expliquer pourquoi une analyse spectroscopique ne donne pas à elle seule le rendement de synthèse.

Voir la correction
  1. Le spectre A correspond à l'alcool car il présente une large bande vers $3300\ ^{-1}$. Le spectre B correspond à la cétone car il présente une forte bande vers $1700\ ^{-1}$.
  2. La liaison $-$ d'un alcool donne une bande large autour de $3300\ ^{-1}$. Le groupe carbonyle $=$ donne une bande intense autour de $1700\ ^{-1}$. Ces deux indices permettent l'association.
  3. Un spectre identifie des fonctions chimiques, mais il ne donne pas directement la quantité de matière obtenue. Pour le rendement, il faut mesurer la masse ou la quantité de produit purifié.

Exercice 10 : Préparation d'un polyamide

Un polyamide peut être obtenu par réaction entre une molécule portant deux fonctions acide carboxylique et une molécule portant deux fonctions amine. À chaque formation de liaison amide, une petite molécule est éliminée.

  1. Donner le nom général d'une réaction qui fabrique une macromolécule par répétition d'un motif.
  2. Expliquer pourquoi les monomères doivent posséder deux fonctions réactives.
  3. Schématiser la formation d'une liaison amide entre $-COO$ et ${}_2-{}_2$.
  4. Citer un intérêt et une limite environnementale de la fabrication de polymères.

Voir la correction
  1. La réaction générale s'appelle une polymérisation.
  2. Chaque monomère doit posséder deux fonctions réactives pour pouvoir se lier à deux voisins et former une chaîne.
  3. Schéma simplifié :
    $$$-COO + {}_2-{}_2 -CON-{}_2 + {}_2$$
    $
    La liaison formée est une liaison amide.
  4. Intérêt : obtenir des matériaux résistants et utiles. Limite : consommation de ressources, déchets, difficulté de recyclage ou pollution par des plastiques.

Exercice 11 : Stratégie de synthèse d'une hormone stéroïdienne

Une molécule $A$, dérivée du cholestérol, possède un groupe alcool et un groupe carbonyle. On souhaite obtenir une molécule $B$ dans laquelle le groupe alcool de $A$ est oxydé en carbonyle tandis que l'autre carbonyle est réduit en alcool.

On dispose des informations suivantes :

  • $Na{}_4$ réduit sélectivement un groupe carbonyle en alcool ;
  • un oxydant à base de dichromate transforme un alcool en carbonyle ;
  • certaines protections permettent de masquer temporairement un groupe carbonyle.

  1. Expliquer pourquoi faire directement l'oxydation puis la réduction peut poser un problème de sélectivité.
  2. Proposer une stratégie en plusieurs étapes utilisant une protection.
  3. Préciser le rôle de chaque étape.
  4. Indiquer deux vérifications expérimentales permettant de valider le produit final.

Voir la correction
Idée directrice : le problème est la sélectivité. Deux groupes peuvent être transformés, mais pas dans le même sens. Il faut donc empêcher temporairement l'un d'eux de réagir.
  1. Si on réduit directement, le groupe carbonyle de $A$ est transformé en alcool. Si on oxyde directement, le groupe alcool est transformé en carbonyle. Mais une étape réalisée au mauvais moment peut modifier un groupe que l'on voulait conserver ou obtenir une molécule intermédiaire non contrôlée.
  2. Une stratégie cohérente est : protéger le carbonyle initial, oxyder l'alcool en carbonyle, déprotéger le carbonyle initial, puis réduire sélectivement le carbonyle voulu si nécessaire selon la structure cible.
  3. Rôle des étapes : la protection empêche un groupe carbonyle de réagir ; l'oxydation transforme l'alcool ; la déprotection restitue le groupe masqué ; la réduction par $Na{}_4$ transforme sélectivement un carbonyle en alcool.
  4. On peut vérifier le produit par spectroscopie infrarouge, RMN, chromatographie, température de fusion ou comparaison avec une référence pure.

Exercice 12 : Synthèse écoresponsable d'une chalcone

Une chalcone est synthétisée par réaction entre une cétone aromatique $A$ et un aldéhyde aromatique $B$ en présence d'hydroxyde de sodium. L'équation simplifiée est :

$$$ + chalcone + {}_2$$
$

On introduit $m_A=$1{,}34 $$ de $A$ de masse molaire $M_A={g.mol^{-1}}$ et $m_B=$1{,}36 $$ de $B$ de masse molaire $M_B={g.mol^{-1}}$. Le produit obtenu après purification a une masse $m=$1{,}90 $$ et une masse molaire $M={g.mol^{-1}}$.
  1. Calculer les quantités de matière initiales de $A$ et $B$.
  2. Déterminer le réactif limitant, sachant que les coefficients stœchiométriques sont 1:1.
  3. Calculer la masse maximale de chalcone attendue.
  4. Calculer le rendement de la synthèse.
  5. Proposer trois arguments permettant de discuter le caractère écoresponsable de cette synthèse.

Voir la correction
  1. Quantité de matière de $A$ :
    $$n_A = {M_A} = {1{,}34}{134} = 1{,}0010^{-2}\ $$
    Quantité de matière de $B$ :
    $$n_B = {M_B} = {1{,}36}{136} = 1{,}0010^{-2}\ $$
  2. Les coefficients sont 1:1 et les quantités initiales sont égales. Les deux réactifs sont introduits dans les proportions stœchiométriques ; aucun n'est en excès.
  3. La quantité maximale de chalcone est donc :
    $$n_{}=1{,}0010^{-2}\ $$
    La masse maximale vaut :
    $$m_{}=n_{}M=1{,}0010^{-2}252=2{,}52\ $$
  4. Rendement :
    $$ = {m_{}}{m_{}}={1{,}90}{2{,}52}=0{,}754$$
    Donc $ 75{,}4
