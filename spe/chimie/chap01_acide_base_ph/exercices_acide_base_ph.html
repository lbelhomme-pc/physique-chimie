Exercice 1 : Couples acide-base et demi-équations

On considère les espèces chimiques suivantes : $H$, $-$, $HCOO$, $HCO-$, ${}_2{}_4$, $H{}_4-$, ${}_3$, ${}_4 + $, ${}_2$, $H-$.

  1. Identifier les couples acide-base présents parmi ces espèces.
  2. \'Ecrire la demi-équation acido-basique associée à chaque couple identifié.
  3. Pour chaque couple, préciser quelle espèce est l'acide et quelle espèce est la base conjuguée.
  4. L'eau ${}_2$ appara\^it-elle dans plusieurs couples ? Comment qualifie-t-on une telle espèce ?
Voir la correction
  1. Identification des acides et des bases dans les couples donnés :
    Rappel \
    $$2pt] Un acide de Br nsted cède un proton $ + $. Une base de Br nsted capte un proton $ + $. Un couple acide-base se note acide/base et est relié par la demi-équation : \[ $acide base + +$$
    $
    • Couple ${}_3COO$/${}_3CO-$ :
      • ${}_3COO$ est l'acide (il cède $ + $).
      • ${}_3CO-$ est la base conjuguée (elle capte $ + $).
      • Demi-équation : ${${}_3COO {}_3CO- + + $}$
    • Couple ${}_4 + $/${}_3$ :
      • ${}_4 + $ est l'acide.
      • ${}_3$ est la base conjuguée.
      • Demi-équation : ${${}_4 + {}_3 + + $}$
    • Couple ${}_3 + $/${}_2$ :
      • ${}_3 + $ est l'acide (l'ion oxonium).
      • ${}_2$ est la base conjuguée.
      • Demi-équation : ${${}_3 + {}_2 + + $}$
    • Couple ${}_2$/$H-$ :
      • ${}_2$ est l'acide.
      • $H-$ est la base conjuguée.
      • Demi-équation : ${${}_2 H- + + $}$
    • Couple ${}_2{}_3$/$H{}_3-$ :
      • ${}_2{}_3$ est l'acide (acide carbonique).
      • $H{}_3-$ est la base conjuguée (ion hydrogénocarbonate).
      • Demi-équation : ${${}_2{}_3 H{}_3- + + $}$
    • Couple $H{}_3-$/${}_3^{2-}$ :
      • $H{}_3-$ est l'acide.
      • ${}_3^{2-}$ est la base conjuguée (ion carbonate).
      • Demi-équation : ${$H{}_3- {}_3^{2-} + + $}$
  2. Pour identifier si une espèce est un acide ou une base, il suffit de regarder si elle peut céder un proton $ + $ (acide) ou en capter un (base). L'acide possède toujours un $$ de plus que sa base conjuguée.

    Exercice 3 : pH et concentration en ions oxonium

    Données \\[2pt] $ = -([${}_3 + $])$ et $[${}_3 + $] = 10^{-}$ (concentrations en {mol.L^{-1}}).
    1. Calculer le pH des solutions suivantes :
      1. Solution A : $[${}_3 + $] = {mol.L^{-1}}$
      2. Solution B : $[${}_3 + $] = {mol.L^{-1}}$
      3. Solution C : $[${}_3 + $] = {mol.L^{-1}}$
    2. Pour chaque solution, préciser si elle est acide, basique ou neutre.
    3. Calculer la concentration en ions oxonium $[${}_3 + $]$ des solutions suivantes :
      1. Solution D : $ = 2{,}3$
      2. Solution E : $ = 11{,}5$
    4. Le pH d'un jus de citron est de $2{,}5$ et celui d'un savon liquide est de $9{,}8$. Combien de fois la concentration en ions oxonium du jus de citron est-elle plus grande que celle du savon ?
    Voir la correction
    1. Définition : une espèce amphotère (ou ampholyte) est une espèce chimique qui peut jouer à la fois le r\^ole d'acide dans un couple et de base dans un autre couple.
    2. {L'eau ${}_2$ est un ampholyte.}

      Justification : l'eau appartient à deux couples acide-base :

      • Couple ${}_3 + $/${}_2$ : l'eau y joue le r\^ole de base (elle capte $ + $) :
        $$${}_2 + + {}_3 +$$
        $
      • Couple ${}_2$/$H-$ : l'eau y joue le r\^ole d'acide (elle cède $ + $) :
        $$${}_2 H- + +$$
        $

      ${{L'eau est amphotère car elle est acide du couple ${}_2$/$H-$ et base du couple ${}_3 + $/${}_2$.}}$

    3. {L'ion hydrogénocarbonate $H{}_3-$ est un ampholyte.}

      Justification : $H{}_3-$ appartient à deux couples :

      • Couple ${}_2{}_3$/$H{}_3-$ : $H{}_3-$ y joue le r\^ole de base :
        $$$H{}_3- + + {}_2{}_3$$
        $
      • Couple $H{}_3-$/${}_3^{2-}$ : $H{}_3-$ y joue le r\^ole d'acide :
        $$$H{}_3- {}_3^{2-} + +$$
        $

      ${{$H{}_3-$ est amphotère car il est acide du couple $H{}_3-$/${}_3^{2-}$ et base du couple ${}_2{}_3$/$H{}_3-$.}}$

    4. La réaction d'autoprotolyse de l'eau met en évidence son caractère amphotère. Une molécule d'eau joue le r\^ole d'acide et une autre le r\^ole de base :
      $${${}_2 + {}_2 {}_3 + + H-$}$$
