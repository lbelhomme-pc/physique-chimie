Exercice 1

Acide fort ou acide faible ?

Pour chacune des espèces suivantes, indiquer s'il s'agit d'un acide fort ou d'un acide faible. Justifier à l'aide du $K_a$ du couple correspondant ou de la nature de la réaction avec l'eau.

  1. L'acide chlorhydrique $H$ (réaction totale avec l'eau).
  2. L'acide éthanoïque ${}_3COO$ ($K_a(${}_3COO/{}_3CO^{-}$) = 4{,}8$).
  3. L'acide nitrique $H{}_3$ (réaction totale avec l'eau).
  4. L'acide méthanoïque $HCOO$ ($K_a($HCOO/HCO^{-}$) = 3{,}8$).
Voir la correction
Méthode : Un acide fort réagit totalement avec l'eau : la réaction est totale, le taux d'avancement final vaut $ = 1$. Un acide faible ne réagit que partiellement avec l'eau : $ < 1$. Un acide dont le $K_a$ est très négatif (ou dont on nous dit que la réaction est totale) est un acide fort. Un acide dont le $K_a$ est positif et significatif est un acide faible.
  1. {L'acide chlorhydrique $H$ :} Données : L'énoncé précise que la réaction de $H$ avec l'eau est totale.

    La réaction s'écrit :

    $$$H(g) + {}_2() {}_3^ + (aq) + ^{-}(aq)$$
    $

    La flèche simple ($$) indique que la réaction est totale. Tout l'acide chlorhydrique est consommé.

    Conclusion : $H$ est un acide fort.
  2. {L'acide éthanoïque ${}_3COO$ :} Données : $K_a(${}_3COO/{}_3CO^{-}$) = 4{,}8$.

    La réaction avec l'eau s'écrit :

    $$${}_3COO(aq) + {}_2() {}_3CO^{-}(aq) + {}_3^ + (aq)$$
    $

    La double flèche ($$) indique un équilibre : la réaction n'est pas totale.

    De plus, le $K_a = 4{,}8 > 0$ : la constante d'acidité $K_a = 10^{-4{,}8} {1{,}6e-5}{}$, qui est très inférieure à 1. Cela confirme que l'acide ne se dissocie que partiellement.

    Conclusion : ${}_3COO$ est un acide faible.
  3. {L'acide nitrique $H{}_3$ :} Données : L'énoncé précise que la réaction de $H{}_3$ avec l'eau est totale.

    La réaction s'écrit :

    $$$H{}_3() + {}_2() {}_3^ + (aq) + {}_3^{-}(aq)$$
    $

    Tout l'acide nitrique est consommé lors de la dissolution.

    Conclusion : $H{}_3$ est un acide fort.
  4. {L'acide méthanoïque $HCOO$ :} Données : $K_a($HCOO/HCO^{-}$) = 3{,}8$.

    La réaction avec l'eau s'écrit :

    $$$HCOO(aq) + {}_2() HCO^{-}(aq) + {}_3^ + (aq)$$
    $

    Le $K_a = 3{,}8 > 0$ donc $K_a = 10^{-3{,}8} {1{,}6e-4}{}$, valeur très inférieure à 1. La réaction avec l'eau est un équilibre, elle n'est pas totale.

    Conclusion : $HCOO$ est un acide faible.

Exercice 2

Dissolution d'un acide fort dans l'eau

L'acide nitrique est un acide fort.

  2. Préciser pourquoi cette réaction est qualifiée de totale .
  3. Déterminer les concentrations en quantité de matière de toutes les espèces chimiques présentes dans la solution $S$.
  4. Calculer le pH de la solution $S$.
Voir la correction
Méthode : Pour un acide fort, la réaction avec l'eau est totale. On écrit l'équation avec une flèche simple, puis on détermine les concentrations à partir de la stoechiométrie (tout l'acide est consommé). Le pH se calcule par $ = -$.
Données : $n = {5{,}0e-3}{}$, $V = $500 $ = {0{,}500}{}$, acide fort.

    L'acide nitrique est un acide fort, la réaction est totale :

    $$$H{}_3() + {}_2() {}_3^ + (aq) + {}_3^{-}(aq)$$
    $
  2. Justification du caractère total :

    La réaction est qualifiée de totale car l'acide nitrique réagit intégralement avec l'eau : à l'état final, il ne reste plus de molécules $H{}_3$ en solution. Le taux d'avancement final vaut $ = 1$ (soit 100

    Commençons par calculer la concentration apportée en acide :

    $$
    c &= {V} = {5{,}0 10^{-3}}{0{,}500} = {1{,}0e-2}{}
    $$

    La réaction étant totale, d'après la stoechiométrie (coefficients tous égaux à 1) :

    • $H{}_3$ est entièrement consommé : $[$H{}_3$] = $0 $$
    • $[${}_3^ + $] = c = {1{,}0e-2}{}$
    • $[${}_3^{-}$] = c = {1{,}0e-2}{}$

    On peut aussi mentionner les ions hydroxyde issus de l'autoprotolyse de l'eau :

    $$
    [$H^{-}$] &= {[${}_3^ + $]} = {1{,}0 10^{-14}}{1{,}0 10^{-2}} = {1{,}0e-12}{}
    $$

    Cette concentration est négligeable devant les autres.

  3. Calcul du pH :

    Méthode : $ = -$ Application numérique :
    $$ &= -(1{,}0 10^{-2}) \\ &= -(-2{,}0) \\ &= 2{,}0 $$
    Conclusion : Le pH de la solution $S$ vaut $ = 2{,}0$. La solution est acide (pH $< 7$), ce qui est cohérent avec la dissolution d'un acide.

Exercice 4

Espèce prédominante et diagramme de prédominance

On considère le couple acide/base ${}_3COO/{}_3CO^{-}$ dont le $K_a$ vaut $4{,}8$.

  1. Rappeler la relation entre le pH d'une solution, le $K_a$ du couple et les concentrations des espèces acide et basique (relation de Henderson-Hasselbalch).
  2. Tracer sur un axe gradué en pH le diagramme de prédominance du couple ${}_3COO/{}_3CO^{-}$.
  3. Déterminer l'espèce prédominante du couple dans chacune des solutions suivantes :
    1. une solution de pH $= 3{,}0$ ;
    2. une solution de pH $= 4{,}8$ ;
    3. une solution de pH $= 7{,}0$.
  4. Pour le couple ammonium/ammoniac $${}_4^ + /{}_3$$ ($K_a = 9{,}2$), déterminer l'espèce prédominante dans une solution de pH $= 7{,}0$.
Voir la correction
Méthode : La relation de Henderson-Hasselbalch relie le pH, le $K_a$ et le rapport des concentrations des formes basique et acide d'un couple. Le diagramme de prédominance permet de savoir quelle espèce prédomine selon le pH.
Données : Couple ${}_3COO/{}_3CO^{-}$, $K_a = 4{,}8$.
  1. Relation de Henderson-Hasselbalch :

    Pour un couple acide/base $$A/^{-}$$, la relation s'écrit :

    $${ = K_a + ({[$^{-}$]}{[$A$]})}$$

    Appliquée au couple ${}_3COO/{}_3CO^{-}$ :

    $$ = 4{,}8 + ({[${}_3CO^{-}$]}{[${}_3COO$]})$$
  2. Diagramme de prédominance :

    Le principe est le suivant :

    • Si $ < K_a$ : alors $({[$^{-}$]}{[$A$]}) < 0$, donc $[$A$] > [$^{-}$]$ : l'acide ${}_3COO$ prédomine.
    • Si $ = K_a$ : alors $[$A$] = [$^{-}$]$ : les deux espèces sont en concentrations égales.
    • Si $ > K_a$ : alors $[$^{-}$] > [$A$]$ : la base ${}_3CO^{-}$ prédomine.

  3. Espèce prédominante selon le pH :
    1. {pH $= 3{,}0$ :} On a $3{,}0 < 4{,}8$ donc $ < K_a$.

      L'espèce prédominante est {${}_3COO$} (la forme acide).

      Vérifions : $({[${}_3CO^{-}$]}{[${}_3COO$]}) = 3{,}0 - 4{,}8 = -1{,}8$, donc ${[${}_3CO^{-}$]}{[${}_3COO$]} = 10^{-1{,}8} 0{,}016$. L'acide est environ 63 fois plus concentré que la base.

    2. {pH $= 4{,}8$ :} On a $ = K_a$.

      Alors $({[${}_3CO^{-}$]}{[${}_3COO$]}) = 0$, donc ${[${}_3CO^{-}$]}{[${}_3COO$]} = 1$.

      Les deux espèces sont en concentrations égales. Aucune ne prédomine.
    3. {pH $= 7{,}0$ :} On a $7{,}0 > 4{,}8$ donc $ > K_a$.

      L'espèce prédominante est {${}_3CO^{-}$} (la forme basique).

      Vérifions : $({[${}_3CO^{-}$]}{[${}_3COO$]}) = 7{,}0 - 4{,}8 = 2{,}2$, donc ${[${}_3CO^{-}$]}{[${}_3COO$]} = 10^{2{,}2} 158$. La base est largement majoritaire.

  4. {Couple $${}_4^ + /{}_3$$ à pH $= 7{,}0$ :}

    Données : $K_a = 9{,}2$.

    On compare : $ = 7{,}0 < 9{,}2 = K_a$.

    Comme $ < K_a$, c'est la forme acide du couple qui prédomine.

    Conclusion : L'espèce prédominante à pH $= 7{,}0$ est {${}_4^ + $} (l'ion ammonium).
    Remarque : À pH physiologique ($ 7{,}4$), l'ion ammonium $${}_4^ + $$ prédomine encore largement sur l'ammoniac $${}_3$$, car le pH reste bien inférieur au $K_a = 9{,}2$.

    6. Exploitation et comparaison :
      1. Cohérence du pH de $S_1$ avec le diagramme de prédominance :

        Pour l'acide nitrique, $K_a {1{,}6e6}{}$, ce qui donne $K_a = -(1{,}6 10^{6}) -6{,}2$.

        Le diagramme de prédominance du couple $$H{}_3/{}_3^{-}$$ a sa frontière à $K_a -6{,}2$. Pour $ > -6{,}2$ (c'est-à-dire pour tout pH positif accessible en solution aqueuse), c'est la forme basique $${}_3^{-}$$ qui prédomine.

        Or le pH de $S_1$ vaut $2{,}0 -6{,}2$. On est donc très largement dans le domaine de prédominance de $${}_3^{-}$$ : il n'y a effectivement plus de $H{}_3$ en solution, ce qui est cohérent avec le fait que toute la molécule a réagi (acide fort).

        Conclusion : Le pH de $S_1$ est bien cohérent avec le diagramme de prédominance.
      2. Comparaison de la force des deux acides :

        Les deux solutions ont été préparées à la même concentration $c = {1{,}0e-2}{}$.

        Or :

        • $_1 = 2{,}0$ pour l'acide nitrique (acide fort)
        • $_2 = 3{,}4$ pour l'acide éthanoïque (acide faible)

        On constate que $_1 < _2$, ce qui signifie que $[${}_3^ + $]_1 > [${}_3^ + $]_2$.

        Interprétation : À concentration égale, l'acide nitrique libère plus d'ions oxonium que l'acide éthanoïque. Cela montre que l'acide nitrique est un acide plus fort que l'acide éthanoïque.

        Pour l'acide fort : $[${}_3^ + $] = c = {1{,}0e-2}{}$ (tout l'acide a réagi).

        Pour l'acide faible : $[${}_3^ + $] = {4{,}1e-4}{}$ (seule une petite fraction a réagi).

        Conclusion : Plus le pH est bas à concentration égale, plus l'acide est fort. L'acide nitrique est un acide plus fort que l'acide éthanoïque.
      3. Méthode pour corriger l'erreur d'étiquetage :

        Si les étiquettes sont interverties, il faut identifier quelle bouteille contient l'acide fort et laquelle contient l'acide faible.

        Méthode proposée : mesure du pH avec un pH-mètre.

        On mesure le pH de chaque solution :

        • La solution de pH $ 2{,}0$ est la solution d'acide nitrique $S_1$ (acide fort : pH plus bas).
        • La solution de pH $ 3{,}4$ est la solution d'acide éthanoïque $S_2$ (acide faible : pH plus élevé).

        Justification : À même concentration, l'acide fort produit plus d'ions oxonium que l'acide faible, donc son pH est plus bas. La simple mesure du pH permet de les distinguer sans ambiguïté.
        Remarque : On pourrait aussi mesurer la conductivité des deux solutions. L'acide fort $S_1$ a une conductivité plus élevée car il est entièrement dissocié, produisant davantage d'ions (et notamment plus de $${}_3^ + $$, qui a la conductivité molaire ionique la plus élevée).
