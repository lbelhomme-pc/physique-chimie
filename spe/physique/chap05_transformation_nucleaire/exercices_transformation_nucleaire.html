Exercice 1

Stabilité des noyaux et vocabulaire nucléaire
  1. Rappeler la composition d'un noyau atomique. Définir les termes nucléons, protons et neutrons.
  2. Donner la notation symbolique d'un noyau ${}^{A}_{Z}$. Préciser la signification de $A$ et de $Z$.
  3. Deux noyaux isotopes sont des noyaux qui possèdent :
    1. le même nombre de protons et de neutrons ;
    2. le même nombre de protons, mais des nombres de neutrons différents ;
    3. le même nombre de neutrons, mais des nombres de protons différents.
    Recopier la bonne réponse et justifier.
  4. L'élément potassium ($Z = 19$) possède trois isotopes naturels : ${}^{39}_{19}$, ${}^{40}_{19}$ et ${}^{41}_{19}$. Déterminer le nombre de protons et de neutrons de chacun de ces isotopes.
Voir la correction
Méthode : Cet exercice porte sur le vocabulaire de base de la physique nucléaire. Il faut connaître la composition du noyau, la notation symbolique et la définition d'isotopes.
1. Un noyau atomique est constitué de nucléons, qui sont de deux types :
  • les protons, de charge électrique positive $+e$ ;
  • les neutrons, électriquement neutres.
Le terme nucléons désigne donc l'ensemble des particules présentes dans le noyau (protons + neutrons). 2. La notation symbolique d'un noyau est : ${}^{A}_{Z}$

où :

  • $A$ est le nombre de masse : c'est le nombre total de nucléons ($A = Z + N$, avec $N$ le nombre de neutrons) ;
  • $Z$ est le numéro atomique : c'est le nombre de protons dans le noyau ;
  • X est le symbole chimique de l'élément.

3. La bonne réponse est b) : deux noyaux isotopes sont des noyaux qui possèdent le même nombre de protons, mais des nombres de neutrons différents. Justification : Des isotopes appartiennent au même élément chimique (même $Z$), mais diffèrent par leur nombre de masse $A$, donc par leur nombre de neutrons $N = A - Z$. 4. Pour l'élément potassium, $Z = 19$ pour les trois isotopes (même nombre de protons). Le nombre de neutrons est $N = A - Z$ :
{1.4}
Isotope$A$$Z$ (protons)$N = A - Z$ (neutrons)
${}^{39}_{19}$3919$39 - 19 = 20$
${}^{40}_{19}$4019$40 - 19 = 21$
${}^{41}_{19}$4119$41 - 19 = 22$
Conclusion : Les trois isotopes ont bien le même nombre de protons (19) mais des nombres de neutrons différents (20, 21 et 22).

Exercice 2

Diagramme $(N ; Z)$ et stabilité

On considère le diagramme $(N ; Z)$ ci-dessous, représentant la zone de stabilité des noyaux (vallée de stabilité).

  1. Pour les noyaux légers (petits $Z$), quelle relation simple existe entre $N$ et $Z$ dans la zone de stabilité ?
  2. Pour les noyaux lourds, la courbe de stabilité s'écarte de la droite $N = Z$. Les noyaux stables possèdent-ils plus de protons ou plus de neutrons ? Proposer une explication.
  3. Placer approximativement sur le diagramme les noyaux suivants et indiquer s'ils sont vraisemblablement stables ou instables :
    1. ${}^{12}_{6}$ (carbone-12) ;
    2. ${}^{14}_{6}$ (carbone-14) ;
    3. ${}^{238}_{92}$ (uranium-238).
Voir la correction
Méthode : Pour utiliser le diagramme $(N ; Z)$, on calcule $N = A - Z$ pour chaque noyau, puis on place le point $(N ; Z)$. Si le point est dans la vallée de stabilité, le noyau est stable ; sinon, il est instable (radioactif).
1. Pour les noyaux légers (petits $Z$), la zone de stabilité suit approximativement la droite $N = Z$. Autrement dit, les noyaux légers stables possèdent autant de neutrons que de protons. 2. Pour les noyaux lourds, la courbe de stabilité s'écarte de la droite $N = Z$ vers le haut (valeurs de $N$ plus grandes). Les noyaux stables lourds possèdent donc plus de neutrons que de protons. Explication : Dans un noyau lourd, le nombre de protons est élevé et la répulsion électrique (coulombienne) entre protons devient très importante. Pour compenser cette répulsion et maintenir la cohésion du noyau grâce à l'interaction forte, il faut un excès de neutrons qui contribuent à l'interaction forte sans ajouter de répulsion électrique. 3. Plaçons les noyaux sur le diagramme :
  1. ${}^{12}_{6}$ : $Z = 6$, $N = 12 - 6 = 6$, donc le point $(N ; Z) = (6 ; 6)$.

    Ce point est sur la droite $N = Z$, dans la vallée de stabilité pour les noyaux légers.

    Conclusion : Le carbone-12 est stable.
  2. ${}^{14}_{6}$ : $Z = 6$, $N = 14 - 6 = 8$, donc le point $(N ; Z) = (8 ; 6)$.

    Ce point est situé à droite de la droite $N = Z$ (excès de neutrons par rapport au carbone-12 stable), en dehors de la vallée de stabilité.

    Conclusion : Le carbone-14 est instable (radioactif).
  3. ${}^{238}_{92}$ : $Z = 92$, $N = 238 - 92 = 146$, donc le point $(N ; Z) = (146 ; 92)$.

    Ce point est très loin de la droite $N = Z$ ($N Z$). De plus, les noyaux très lourds ($Z > 83$) sont tous instables.

    Conclusion : L'uranium-238 est instable (radioactif).

Exercice 4

Écriture d'équations de réaction nucléaire

Pour chaque désintégration, écrire l'équation de la réaction nucléaire en appliquant les lois de conservation du nombre de masse $A$ et du numéro atomique $Z$.

  1. Le radium-226 (${}^{226}_{88}$) subit une désintégration $$. Identifier le noyau fils formé.
  2. Le carbone-14 (${}^{14}_{6}$) subit une désintégration $^{-}$. Identifier le noyau fils formé.
  3. Le francium-205 (${}^{205}_{87}$) subit une désintégration $$. Identifier le noyau fils formé.
  4. Le phosphore-30 (${}^{30}_{15}$) subit une désintégration $^{+}$. Identifier le noyau fils formé.
Données : Extrait du tableau périodique -- Rn ($Z=86$), At ($Z=85$), N ($Z=7$), Si ($Z=14$).
Voir la correction
Méthode : Pour écrire une équation de réaction nucléaire, on applique deux lois de conservation :
  • Conservation du nombre de masse $A$ : la somme des $A$ des réactifs = la somme des $A$ des produits.
  • Conservation du numéro atomique $Z$ : la somme des $Z$ des réactifs = la somme des $Z$ des produits.
On identifie ensuite le noyau fils à l'aide du tableau périodique.
1. Désintégration $$ du radium-226

L'équation s'écrit :

$${}^{226}_{88} {}^{A}_{Z} + {}^{4}_{2}$$

Conservation de $A$ : $226 = A + 4$, donc $A = 222$. Conservation de $Z$ : $88 = Z + 2$, donc $Z = 86$.

L'élément de numéro atomique $Z = 86$ est le radon (Rn).

$${{}^{226}_{88} {}^{222}_{86} + {}^{4}_{2}}$$

{2. Désintégration $^{-}$ du carbone-14}

L'équation s'écrit :

$${}^{14}_{6} {}^{A}_{Z} + {}^{0}_{-1} + _e$$

Conservation de $A$ : $14 = A + 0$, donc $A = 14$. Conservation de $Z$ : $6 = Z + (-1)$, donc $Z = 7$.

L'élément de numéro atomique $Z = 7$ est l'azote (N).

$${{}^{14}_{6} {}^{14}_{7} + {}^{0}_{-1} + _e}$$
3. Désintégration $$ du francium-205

L'équation s'écrit :

$${}^{205}_{87} {}^{A}_{Z} + {}^{4}_{2}$$

Conservation de $A$ : $205 = A + 4$, donc $A = 201$. Conservation de $Z$ : $87 = Z + 2$, donc $Z = 85$.

L'élément de numéro atomique $Z = 85$ est l'astate (At).

$${{}^{205}_{87} {}^{201}_{85} + {}^{4}_{2}}$$

{4. Désintégration $^{+}$ du phosphore-30}

L'équation s'écrit :

$${}^{30}_{15} {}^{A}_{Z} + {}^{0}_{+1} + _e$$

Conservation de $A$ : $30 = A + 0$, donc $A = 30$. Conservation de $Z$ : $15 = Z + 1$, donc $Z = 14$.

L'élément de numéro atomique $Z = 14$ est le silicium (Si).

$${{}^{30}_{15} {}^{30}_{14} + {}^{0}_{+1} + _e}$$
