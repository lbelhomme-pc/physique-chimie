Formation d'images par une lunette astronomique

{ Objectifs du chapitre}
  • Comprendre le modèle optique d'une lunette astronomique afocale (objectif + oculaire).
  • Savoir réaliser la construction graphique du trajet d'un faisceau lumineux dans une lunette afocale.
  • Définir et calculer le grossissement $G$ d'une lunette astronomique.
  • Connaître les caractéristiques d'une lunette commerciale : grossissement, luminosité, nombre d'ouverture.

1. La lunette astronomique afocale

1.1 Qu'est-ce qu'une lunette astronomique ?

Une lunette astronomique est un instrument d'optique qui permet d'observer des objets très éloignés (astres, planètes, étoiles). Elle rend l'image d'un astre plus grosse que lorsque cet astre est observé à l' il nu.

Remarque : la lunette astronomique ne ``rapproche'' pas les objets. Elle augmente l'angle sous lequel on les voit, ce qui donne l'impression qu'ils sont plus gros.

1.2 Modèle optique

Dans le cadre du modèle de la lentille mince, une lunette astronomique peut être modélisée par un système de deux lentilles minces convergentes ayant un axe optique commun :

L'objectif : c'est la lentille convergente placée du côté de l'objet observé (côté du ciel). Elle est caractérisée par :
  • son centre optique $O_1$ ;
  • sa distance focale $f'_1$ (grande, de l'ordre du mètre).
L'oculaire : c'est la lentille convergente placée du côté de l' il de l'observateur. Elle est caractérisée par :
  • son centre optique $O_2$ ;
  • sa distance focale $f'_2$ (petite, de l'ordre du centimètre).
Remarque importante : la distance focale de l'objectif $f'_1$ est beaucoup plus grande que la distance focale de l'oculaire $f'_2$. C'est cette différence qui permet d'obtenir un grossissement important.

1.3 Condition d'afocalité

Pour qu'un observateur puisse regarder à travers la lunette sans effort (vision ``au repos'', comme s'il regardait un objet à l'infini), la lunette doit être réglée de manière afocale.

Voici le raisonnement, étape par étape :

  1. L'objet observé (un astre) est situé ``à l'infini''. De chaque point de cet objet arrive un faisceau de rayons parallèles entre eux.
  2. L'image d'un objet situé à l'infini, formée par l'objectif (lentille $L_1$), se situe dans le plan focal image de l'objectif, c'est-à-dire au point $F'_1$.
  3. Cette image intermédiaire devient un objet réel pour l'oculaire (lentille $L_2$).
  4. Pour que l'image définitive (celle que voit l' il) soit elle aussi à l'infini (vision sans effort), l'image intermédiaire doit se situer dans le plan focal objet de l'oculaire, c'est-à-dire au point $F_2$.

2. Image formée par une lunette afocale

2.1 Construction graphique -- Principes

Pour construire le trajet d'un faisceau lumineux dans la lunette afocale, on suit les étapes suivantes :

Méthode de construction graphique :
  1. Un objet réel plan AB est situé à l'infini, perpendiculairement à l'axe optique, avec le point A sur l'axe. L'objet AB est vu à l' il nu sous un angle $$.
  2. Le faisceau de rayons parallèles issu du point B (situé ``à l'infini'') pénètre dans la lunette.
  3. L'image $B_1$ du point B se forme dans le plan focal image de l'objectif (puisque l'objet est à l'infini). Le point $A_1$ (image de A) est sur l'axe optique, au foyer $F'_1$.
  4. Le point $B_1$ devient un objet réel pour l'oculaire. Puisque $F'_1 = F_2$, le point $B_1$ est dans le plan focal objet de l'oculaire.
  5. \`{A} la sortie de l'oculaire, les rayons issus de $B_1$ ressortent parallèles entre eux. L'image définitive $A'B'$ est donc située ``à l'infini''.
  6. L'image définitive $A'B'$ est vue par l' il sous un angle $'$.

2.2 Caractéristiques des images

  • Image intermédiaire $A_1B_1$ (formée par l'objectif) : elle est plus petite que l'objet AB, réelle et renversée.
  • Image définitive $A'B'$ (observée à travers l'oculaire) : elle est virtuelle, située à l'infini, plus grande (en angle) que l'image intermédiaire et renversée par rapport à l'objet AB.

2.3 Rôles des deux lentilles

Rôle de l'objectif ($L_1$) :
  • Il joue le rôle de collecteur de lumière : il concentre la lumière provenant des étoiles (objets peu lumineux et très éloignés).
  • Il forme l'image intermédiaire $A_1B_1$ dans son plan focal image.
Rôle de l'oculaire ($L_2$) :
  • Il joue le rôle d'une loupe : il agrandit l'image intermédiaire formée par l'objectif.
  • L'image d'un objet formée par une loupe est agrandie et droite (par rapport à l'image intermédiaire).

4. Luminosité d'une lunette astronomique

Le grossissement n'est pas la seule caractéristique importante d'une lunette. La luminosité est également essentielle pour observer des objets peu lumineux (comme des étoiles lointaines).

4.1 Rôle du diamètre de l'objectif

  • Pour l'observation d'objets ponctuels (comme des étoiles très éloignées), c'est le diamètre $D$ de l'objectif qui est déterminant. En effet, plus la surface de l'objectif est grande, plus il collecte de lumière. L'image d'une étoile apparaît alors plus lumineuse qu'à l' il nu.
  • Pour l'observation d'objets étendus (Lune, planètes, nébuleuses), il faut aussi tenir compte de l'étalement de l'énergie lumineuse lié au grossissement, qui dépend de la distance focale de l'objectif $f'_1$.

5. Rappels utiles

5.1 Modèle de la lentille mince -- Domaine de validité

Le modèle de la lentille mince est utilisable dans les conditions suivantes :
  • les rayons lumineux traversent la lentille au voisinage du centre optique ;
  • les rayons sont peu inclinés par rapport à l'axe optique (conditions de Gauss).
