## Objectifs du cours

- Savoir differencier un **atome** d'une **molecule**.
- Savoir lire et ecrire une **formule chimique** (ex: $H_2O$).
- Connaitre les **modeles moleculaires** de base (couleurs des atomes).

---

## 1. Qu'est-ce qu'une molecule ?

<div class="definition-box">

### Definition

Une **molecule** est une entite chimique electriquement neutre constituee d'un **assemblage d'au moins deux atomes** lies entre eux.

</div>

Par exemple, le dioxygene ($O_2$) est forme de deux atomes d'oxygene.

---

## 2. La formule chimique

La formule contient :

- Les **symboles** des atomes presents (toujours une majuscule).
- Le **nombre** de chaque atome en **indice** (en bas a droite). Si un atome est seul, on n'ecrit pas 1.

<div class="methode-box">

### Methode : lire une formule chimique

1. **Identifier** chaque symbole d'atome (commence par une majuscule).
2. **Lire l'indice** apres chaque symbole (s'il n'y en a pas, c'est 1).
3. **Additionner** tous les indices pour obtenir le nombre total d'atomes.

</div>

<div class="example-box">

### Exemple : analyse de $H_2O$

- **H** : 2 atomes d'Hydrogene
- **O** : 1 atome d'Oxygene
- **Total** : 3 atomes dans la molecule

</div>

<div class="box-regle-or">

### Attention : les majuscules sont essentielles !

Ne pas confondre **$Co$** (un atome de Cobalt) et **$CO$** (une molecule : 1 Carbone + 1 Oxygene). **La majuscule fait toute la difference !**

</div>

---

## 3. Les modeles moleculaires

Code couleur international :

| Atome | Symbole | Couleur |
|---|---|---|
| Carbone | $C$ | **Noir** |
| Hydrogene | $H$ | **Blanc** |
| Oxygene | $O$ | **Rouge** |
| Azote | $N$ | **Bleu** |

<div class="info-box">

### A savoir

Les molecules courantes a connaitre :
- **Eau** : $H_2O$ (2H + 1O = 3 atomes)
- **Dioxygene** : $O_2$ (2 atomes d'oxygene)
- **Diazote** : $N_2$ (2 atomes d'azote)
- **Dioxyde de carbone** : $CO_2$ (1C + 2O = 3 atomes)
- **Methane** : $CH_4$ (1C + 4H = 5 atomes)

</div>

---

<div class="retenir-box">

## L'essentiel a retenir

- Une **molecule** = assemblage d'au moins deux atomes.
- La **formule chimique** donne les symboles et le nombre d'atomes.
- Le chiffre **1** ne s'ecrit jamais en indice.
- Attention aux **majuscules** : $Co \neq CO$.
- Code couleur : C = noir, H = blanc, O = rouge, N = bleu.

</div>
