## Objectifs

- Distinguer **espèce chimique** et **entité chimique**.
- Reconnaître une **molécule**, un **atome**, un **anion** et un **cation**.
- Exploiter l'**électroneutralité** pour écrire la formule d'un composé ionique simple.
- Décrire le noyau d'un atome avec A, Z, protons, neutrons et nucléons.
- Écrire et exploiter une **configuration électronique** pour Z ≤ 18.
- Relier stabilité des gaz nobles, ions monoatomiques et schémas de Lewis fournis.

## Prérequis

- Connaître les symboles chimiques courants : <span class="chem-formula">H</span>, <span class="chem-formula">C</span>, <span class="chem-formula">O</span>, <span class="chem-formula">N</span>, <span class="chem-formula">Na</span>, <span class="chem-formula">Cl</span>.
- Savoir qu'un atome contient un noyau et des électrons.
- Savoir qu'une charge positive ou négative indique un ion.
- Savoir lire une formule chimique simple.

## Problématique

Une goutte d'eau contient un très grand nombre de molécules. Comment relier l'échantillon visible à l'oeil nu aux entités chimiques microscopiques qui le constituent ?

## 1. Du macroscopique au microscopique

### Définition

À l'échelle **macroscopique**, on décrit un échantillon avec des espèces chimiques.

À l'échelle **microscopique**, on décrit les entités chimiques : atomes, molécules ou ions.

| Échelle | Ce qu'on décrit | Exemple |
|---|---|---|
| Macroscopique | espèce chimique dans un échantillon | eau, dioxygène, chlorure de sodium |
| Microscopique | entités chimiques | molécule <span class="chem-formula">H<sub>2</sub>O</span>, ion <span class="chem-formula">Na<sup>+</sup></span>, ion <span class="chem-formula">Cl<sup>-</sup></span> |

### Méthode

Pour passer d'une formule à un type d'entité :

1. vérifier si l'entité porte une charge ;
2. si elle est neutre et formée d'un seul symbole : atome ;
3. si elle est neutre et formée de plusieurs atomes : molécule ;
4. si elle porte une charge positive : cation ;
5. si elle porte une charge négative : anion.

### Exemple

<span class="chem-formula">O<sub>2</sub></span> est une molécule car elle est neutre et contient deux atomes d'oxygène.

<span class="chem-formula">Na<sup>+</sup></span> est un cation car il porte une charge positive.

<span class="chem-formula">Cl<sup>-</sup></span> est un anion car il porte une charge négative.

### Erreur fréquente

Une espèce chimique n'est pas une seule entité : c'est une collection d'un très grand nombre d'entités identiques.

## 2. Ions et électroneutralité

### Définition

Un **ion** est une entité chimique chargée.

- Un **cation** est chargé positivement.
- Un **anion** est chargé négativement.

Un échantillon macroscopique de matière est globalement **électriquement neutre** : les charges positives et négatives se compensent.

### Méthode

Pour écrire la formule d'un composé ionique :

1. écrire le cation puis l'anion ;
2. chercher combien d'ions de chaque type sont nécessaires pour obtenir une charge totale nulle ;
3. placer les nombres en indice ;
4. ne pas écrire l'indice 1.

### Exemple

Le calcium donne l'ion <span class="chem-formula">Ca<sup>2+</sup></span> et le fluor donne l'ion <span class="chem-formula">F<sup>-</sup></span>.

Pour compenser +2, il faut deux ions fluorure :

$$\mathrm{Ca^{2+} + 2F^- \rightarrow CaF_2}$$

La formule du fluorure de calcium est <span class="chem-formula">CaF<sub>2</sub></span>.

### Erreur fréquente

La formule d'un composé ionique n'indique pas une molécule isolée. Elle indique les proportions d'ions dans un solide ionique électriquement neutre.

## 3. Le noyau de l'atome

### Définition

Le noyau contient des **protons** et des **neutrons**.

- Z est le numéro atomique : nombre de protons.
- A est le nombre de masse : nombre total de nucléons.
- Nombre de neutrons : A - Z.

L'écriture conventionnelle d'un noyau est :

$$^{A}_{Z}X$$

où X est le symbole de l'élément chimique.

### Méthode

Pour exploiter une écriture nucléaire :

1. lire Z pour connaître le nombre de protons ;
2. lire A pour connaître le nombre de nucléons ;
3. calculer A - Z pour obtenir le nombre de neutrons ;
4. pour un atome neutre, le nombre d'électrons est égal au nombre de protons.

### Exemple

Pour le noyau <span class="chem-formula"><sup>23</sup><sub>11</sub>Na</span> :

- Z = 11, donc il y a 11 protons ;
- A = 23, donc il y a 23 nucléons ;
- nombre de neutrons : 23 - 11 = 12.

Un atome neutre de sodium possède aussi 11 électrons.

### Ordres de grandeur

Un atome mesure environ 10<sup>-10</sup> m. Son noyau mesure environ 10<sup>-15</sup> m. Le noyau est donc environ 100 000 fois plus petit que l'atome, mais il contient presque toute sa masse.

## 4. Configuration électronique

### Définition

La **configuration électronique** décrit la répartition des électrons d'un atome dans les sous-couches électroniques.

En seconde, on utilise les sous-couches 1s, 2s, 2p, 3s, 3p pour les atomes de numéro atomique Z ≤ 18.

Les **électrons de valence** sont les électrons de la couche externe. Ils interviennent fortement dans les propriétés chimiques.

### Méthode

Pour écrire une configuration électronique :

1. déterminer le nombre d'électrons de l'atome neutre : il est égal à Z ;
2. remplir dans l'ordre 1s, 2s, 2p, 3s, 3p ;
3. respecter les capacités : s peut contenir 2 électrons, p peut contenir 6 électrons ;
4. identifier la couche externe pour trouver les électrons de valence.

### Exemple

L'oxygène a Z = 8, donc un atome neutre d'oxygène possède 8 électrons.

Configuration :

$$1s^2\ 2s^2\ 2p^4$$

La couche externe est la couche 2. Elle contient 2 + 4 = 6 électrons de valence.

### Erreur fréquente

Ne pas confondre numéro atomique Z et nombre de masse A. Pour un atome neutre, le nombre d'électrons est égal à Z, pas à A.

## 5. Stabilité chimique et ions monoatomiques

### Définition

Les gaz nobles sont très stables chimiquement. Leur couche externe est complète.

Certains atomes deviennent plus stables en formant des ions monoatomiques dont la configuration électronique se rapproche de celle d'un gaz noble.

### Méthode

Pour prévoir la charge d'un ion monoatomique simple :

1. repérer la famille ou la position dans le tableau périodique ;
2. chercher si l'atome perd ou gagne peu d'électrons pour atteindre une configuration stable ;
3. écrire la charge correspondante.

### Exemples

Le sodium <span class="chem-formula">Na</span> perd souvent un électron : il forme <span class="chem-formula">Na<sup>+</sup></span>.

Le chlore <span class="chem-formula">Cl</span> gagne souvent un électron : il forme <span class="chem-formula">Cl<sup>-</sup></span>.

### Ions à connaître

| Nom | Formule |
|---|---|
| ion hydrogène | <span class="chem-formula">H<sup>+</sup></span> |
| ion sodium | <span class="chem-formula">Na<sup>+</sup></span> |
| ion potassium | <span class="chem-formula">K<sup>+</sup></span> |
| ion calcium | <span class="chem-formula">Ca<sup>2+</sup></span> |
| ion magnésium | <span class="chem-formula">Mg<sup>2+</sup></span> |
| ion chlorure | <span class="chem-formula">Cl<sup>-</sup></span> |
| ion fluorure | <span class="chem-formula">F<sup>-</sup></span> |

## 6. Molécules et schéma de Lewis

### Définition

Une molécule est une entité chimique électriquement neutre constituée de plusieurs atomes liés.

Un **schéma de Lewis** représente les doublets liants et non liants d'une molécule. En seconde, les schémas peuvent être fournis et exploités.

### Méthode

Pour exploiter un schéma de Lewis :

1. repérer les atomes ;
2. repérer les doublets liants entre deux atomes ;
3. repérer les doublets non liants autour d'un atome ;
4. vérifier que les atomes atteignent une configuration plus stable que les atomes isolés.

### Exemple

Dans l'eau <span class="chem-formula">H<sub>2</sub>O</span>, l'oxygène est lié à deux atomes d'hydrogène par deux doublets liants. Il possède aussi deux doublets non liants.

Ce modèle aide à comprendre pourquoi les atomes ne restent pas isolés.

### Erreur fréquente

Le schéma de Lewis est un modèle. Il ne montre pas la forme réelle complète de la molécule, mais il rend visibles les liaisons et certains doublets d'électrons.

## Difficultés prévisibles

| Difficulté | Pourquoi elle bloque | Remédiation |
|---|---|---|
| Confondre espèce et entité | Les deux mots sont proches. | Associer espèce à l'échantillon, entité à la particule microscopique. |
| Confondre atome et ion | Les deux peuvent avoir le même symbole. | Chercher la charge écrite en exposant. |
| Utiliser `A` au lieu de `Z` pour les électrons | L'écriture nucléaire contient deux nombres. | Toujours dire : protons = `Z`, électrons d'un atome neutre = `Z`. |
| Oublier l'électroneutralité | Les formules ioniques semblent arbitraires. | Additionner les charges pour obtenir zéro. |
| Lire Lewis comme une photo réelle | Le schéma est très symbolique. | Répéter que c'est un modèle des liaisons et doublets. |

## À retenir

### Définitions essentielles

- Une espèce chimique est une collection d'un très grand nombre d'entités identiques.
- Une entité chimique peut être un atome, une molécule ou un ion.
- Un cation est positif ; un anion est négatif.
- Un atome neutre possède autant d'électrons que de protons.

### Relations importantes

- Nombre de protons : `Z`.
- Nombre de nucléons : `A`.
- Nombre de neutrons : `A - Z`.
- Formule d'un noyau : `^{A}_{Z}X`.

### Méthodes importantes

1. Pour qualifier une entité, regarder la formule et la charge.
2. Pour un composé ionique, utiliser l'électroneutralité.
3. Pour une configuration électronique, remplir `1s`, `2s`, `2p`, `3s`, `3p`.
4. Pour Lewis, repérer doublets liants et non liants.

### Pièges classiques

- Une espèce chimique n'est pas une entité unique.
- Un ion n'est pas électriquement neutre.
- Une formule ionique respecte la neutralité globale.
- Le modèle de Lewis n'est pas une photographie de la molécule.

### Mini-bilan

La chimie de seconde relie l'échelle visible des échantillons à l'échelle microscopique des entités chimiques. Cette modélisation explique la composition, les charges et la stabilité des espèces.
