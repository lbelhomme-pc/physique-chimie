## Objectifs

- Distinguer formule brute, développée et semi-développée.
- Reconnaître un squelette carboné saturé.
- Identifier un groupe caractéristique dans une formule semi-développée.
- Associer un groupe caractéristique à une famille fonctionnelle.
- Reconnaître les alcools, aldéhydes, cétones et acides carboxyliques.
- Justifier le lien entre le nom et la formule semi-développée d'une molécule simple.
- Exploiter un spectre infrarouge à partir de valeurs de référence.

## Prérequis

- Savoir lire une formule chimique.
- Connaître les symboles $C$, $H$ et $O$.
- Savoir que le carbone forme généralement quatre liaisons covalentes.
- Savoir que l'hydrogène forme généralement une liaison et l'oxygène deux.
- Connaître la notion de liaison covalente.
- Savoir lire un graphique simple et repérer une valeur sur un axe.

## Cours

### 1. Les formules des molécules organiques

#### Définition ou idée essentielle

La **formule brute** indique le nombre d'atomes de chaque élément. La **formule développée** montre toutes les liaisons entre les atomes. La **formule semi-développée** regroupe les liaisons avec les hydrogènes tout en conservant l'enchaînement des atomes.

#### Formule ou méthode

Pour passer d'une formule semi-développée à une formule brute :

1. compter les atomes de carbone ;
2. compter les atomes d'hydrogène ;
3. compter les autres atomes ;
4. écrire les indices corrects.

#### Exemple

L'éthanol s'écrit $\mathrm{CH_3-CH_2-OH}$. On compte $2$ atomes de carbone, $6$ d'hydrogène et $1$ d'oxygène : sa formule brute est $\mathrm{C_2H_6O}$. La formule brute ne précise pas seule l'organisation des atomes.

### 2. Le squelette carboné saturé

#### Définition ou idée essentielle

Le **squelette carboné** est l'enchaînement des atomes de carbone d'une molécule organique. Il est **saturé** lorsque les carbones sont reliés uniquement par des liaisons simples C-C.

#### Formule ou méthode

Pour identifier un squelette carboné saturé :

1. repérer les atomes de carbone ;
2. observer les liaisons C-C ;
3. vérifier qu'elles sont toutes simples ;
4. conclure.

Un modèle moléculaire ou un logiciel de visualisation permet de représenter les atomes dans l'espace et de vérifier que le carbone respecte ses quatre liaisons. Il complète la formule semi-développée ; il ne la remplace pas.

Erreur fréquente : regarder seulement les liaisons avec les hydrogènes. La saturation concerne les liaisons entre atomes de carbone.

#### Exemple

Dans $\mathrm{CH_3-CH_2-CH_3}$, les liaisons C-C sont simples : le squelette est saturé. Dans $\mathrm{CH_2=CH_2}$, une double liaison C=C est présente : le squelette n'est pas saturé.

### 3. Les groupes caractéristiques

#### Définition ou idée essentielle

Un **groupe caractéristique** est un groupe d'atomes qui donne à une molécule organique une partie importante de ses propriétés chimiques. Il permet souvent d'identifier une famille fonctionnelle.

#### Formule ou méthode

Pour repérer un groupe caractéristique :

1. observer la formule semi-développée ;
2. repérer les atomes autres que C et H ;
3. chercher des enchaînements particuliers ;
4. comparer avec le tableau de référence.

#### Exemple

Dans $\mathrm{CH_3-CH_2-OH}$, le groupe $\mathrm{-OH}$ est repérable : il caractérise un alcool.

### 4. Les familles fonctionnelles

#### Définition ou idée essentielle

Une **famille fonctionnelle** rassemble des molécules qui possèdent le même groupe caractéristique. Les familles exigibles sont les alcools, les aldéhydes, les cétones et les acides carboxyliques.

#### Formule ou méthode

| Famille | Groupe caractéristique | Exemple |
| --- | --- | --- |
| Alcool | $\mathrm{-OH}$ sur un carbone saturé | éthanol |
| Aldéhyde | $\mathrm{-CHO}$ | éthanal |
| Cétone | $\mathrm{>C=O}$ au sein d'une chaîne | propanone |
| Acide carboxylique | $\mathrm{-COOH}$ | acide éthanoïque |

Pour identifier une famille, repérer le groupe puis vérifier sa position. Aldéhyde et cétone possèdent tous deux C=O : la position de ce groupe les distingue.

$\mathrm{CH_3-CHO}$ est un aldéhyde. $\mathrm{CH_3-CO-CH_3}$ est une cétone. $\mathrm{CH_3-COOH}$ est un acide carboxylique.

### 5. Le lien entre nom et formule semi-développée

#### Définition ou idée essentielle

En première, il faut relier le nom et la formule semi-développée de molécules simples possédant un seul groupe caractéristique. Le préfixe indique le nombre de carbones et le suffixe la famille.

#### Formule ou méthode

| Préfixe | Nombre de carbones | Indice dans le nom | Famille |
| --- | ---: | --- | --- |
| méth- | 1 | -ol | alcool |
| éth- | 2 | -al | aldéhyde |
| prop- | 3 | -one | cétone |
| but- | 4 | acide ...-oïque | acide carboxylique |

Méthode : repérer le préfixe, identifier la famille, placer le groupe caractéristique et vérifier les liaisons de chaque carbone.

### 6. Identifier un groupe caractéristique par spectroscopie infrarouge

#### Définition ou idée essentielle

La spectroscopie infrarouge fournit un spectre lié aux liaisons présentes dans une molécule. Certaines liaisons absorbent dans des domaines de nombres d'onde caractéristiques. Un spectre IR aide à identifier des groupes, mais il doit être croisé avec d'autres informations.

#### Formule ou méthode

Dans un spectre de **transmittance**, le nombre d'onde est exprimé en $\mathrm{cm^{-1}}$ sur l'axe horizontal. Une absorption apparaît sous la forme d'un creux. Les valeurs sont approximatives et peuvent varier selon la molécule.

| Liaison ou groupe | Zone approximative |
| --- | --- |
| O-H d'un alcool | large bande vers $3200-3600\ \mathrm{cm^{-1}}$ |
| O-H d'un acide carboxylique | très large bande vers $2500-3300\ \mathrm{cm^{-1}}$ |
| C=O | bande forte vers $1650-1750\ \mathrm{cm^{-1}}$ |
| C-H | bandes vers $2800-3100\ \mathrm{cm^{-1}}$ |

Méthode : repérer les creux principaux, relever leur nombre d'onde, comparer avec les références, puis croiser avec la formule ou le nom.

## À retenir

### Définitions essentielles

- Une formule brute indique le nombre d'atomes de chaque élément.
- Une formule semi-développée montre l'enchaînement des atomes de manière simplifiée.
- Un squelette carboné saturé ne contient que des liaisons simples entre carbones.
- Un groupe caractéristique permet d'identifier une famille fonctionnelle.
- Un spectre IR aide à identifier certaines liaisons ou certains groupes caractéristiques.

### Groupes caractéristiques à connaître

| Famille | Groupe | Exemple |
| --- | --- | --- |
| Alcool | $\mathrm{-OH}$ | $\mathrm{CH_3-CH_2-OH}$ |
| Aldéhyde | $\mathrm{-CHO}$ | $\mathrm{CH_3-CHO}$ |
| Cétone | $\mathrm{>C=O}$ | $\mathrm{CH_3-CO-CH_3}$ |
| Acide carboxylique | $\mathrm{-COOH}$ | $\mathrm{CH_3-COOH}$ |

### Méthode importante

1. Lire la formule semi-développée.
2. Repérer le groupe caractéristique et sa position.
3. Associer la famille.
4. Utiliser le nom ou le spectre IR pour confirmer.
5. Conclure sans surinterpréter une seule bande IR.

### Pièges classiques

- Une formule brute ne suffit pas toujours à identifier une famille.
- Aldéhyde et cétone possèdent tous deux une liaison C=O, mais pas au même endroit.
- Les nombres d'onde de référence correspondent à des domaines approximatifs.
- Une bande IR isolée ne permet pas toujours une identification unique.
