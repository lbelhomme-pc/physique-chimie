\section{Objectifs}
\begin{itemize}
\item Organiser une série de données.
\item Lire et construire un tableau ou un graphique.
\item Comparer des effectifs et des fréquences.
\item Interpréter une représentation avec esprit critique.
\end{itemize}

\section{1. Effectif}
L'effectif d'une catégorie est le nombre d'individus qui appartiennent à cette catégorie.

Exemple : si 12 élèves sur 30 viennent à vélo, l'effectif « vélo » est 12.

\section{2. Fréquence}
La fréquence d'une catégorie est
\[
\frac{\text{effectif de la catégorie}}{\text{effectif total}}.
\]

Ici :
\[
\frac{12}{30}=0{,}4=40\%.
\]

\section{3. Tableaux}
Un tableau doit comporter des intitulés clairs et, si nécessaire, des unités. On peut y ranger des effectifs, des fréquences ou des mesures.

\section{4. Graphiques}
Selon les données, on peut utiliser :
\begin{itemize}
\item un diagramme en barres ;
\item un diagramme circulaire ;
\item une courbe pour une évolution dans le temps.
\end{itemize}

Le choix du graphique dépend de la question posée.

\section{5. Lecture critique}
Un axe tronqué, une échelle irrégulière ou un choix graphique maladroit peut exagérer ou masquer des différences.

Il faut toujours vérifier :
\begin{itemize}
\item le titre ;
\item les axes ;
\item les unités ;
\item l'échelle ;
\item la population étudiée.
\end{itemize}

\section{Erreurs fréquentes}
\begin{itemize}
\item Confondre effectif et fréquence.
\item Oublier l'effectif total.
\item Comparer visuellement deux graphiques ayant des échelles différentes.
\end{itemize}

\section{À retenir}
Un graphique est une représentation des données, pas les données elles-mêmes. Sa lecture exige de contrôler axes, unités et échelle.
