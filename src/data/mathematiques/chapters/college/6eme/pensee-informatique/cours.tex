\section{Objectifs}
\begin{itemize}
\item Décomposer un problème en instructions.
\item Prévoir le résultat d'un algorithme.
\item Utiliser une variable et une répétition simple.
\item Rechercher une erreur.
\end{itemize}

\section{1. Algorithme}
Un algorithme est une suite finie d'instructions permettant d'obtenir un résultat.

Exemple :
\begin{enumerate}
\item choisir un nombre ;
\item ajouter 4 ;
\item doubler le résultat.
\end{enumerate}

Avec 3 : on obtient 14.

\section{2. Variable}
Une variable mémorise une valeur susceptible de changer.

Pseudo-code :
\begin{verbatim}
x ← 5
x ← x + 3
\end{verbatim}
Après ces deux instructions, $x$ vaut 8.

\section{3. Répétition}
Une boucle permet de répéter une instruction.

\begin{verbatim}
répéter 4 fois
  avancer de 10
\end{verbatim}

En géométrie dynamique ou dans un environnement par blocs, une boucle évite de recopier quatre fois la même instruction.

\section{4. Condition}
Une condition permet de choisir une action selon une situation :
\begin{verbatim}
si score ≥ 10
  afficher "objectif atteint"
sinon
  afficher "continuer"
\end{verbatim}

\section{5. Débogage}
Déboguer consiste à chercher pourquoi un programme ne produit pas le résultat attendu.

Méthode :
\begin{enumerate}
\item prévoir le résultat ;
\item exécuter pas à pas ;
\item repérer la première étape différente ;
\item corriger puis tester à nouveau.
\end{enumerate}

\section{6. Pensée informatique}
Programmer n'est pas seulement écrire du code. Il faut aussi :
\begin{itemize}
\item décomposer un problème ;
\item reconnaître des répétitions ;
\item organiser des informations ;
\item tester des cas ;
\item expliquer une procédure.
\end{itemize}

\section{Erreurs fréquentes}
\begin{itemize}
\item Confondre la valeur d'une variable avant et après une affectation.
\item Répéter une instruction une fois de trop.
\item Modifier plusieurs choses à la fois lors d'un débogage.
\end{itemize}

\section{À retenir}
Un bon algorithme est une suite d'instructions compréhensible, testable et finie. La programmation sert à rendre cette procédure exécutable.
