## Objectifs
- Décomposer un problème en instructions.
- Prévoir le résultat d'un algorithme.
- Utiliser une variable et une répétition simple.
- Rechercher une erreur.

## 1. Algorithme
Un algorithme est une suite finie d'instructions permettant d'obtenir un résultat.

Exemple :
1. choisir un nombre ;
2. ajouter 4 ;
3. doubler le résultat.

Avec 3 : on obtient 14.

## 2. Variable
Une variable mémorise une valeur susceptible de changer.

Pseudo-code :
```text
x ← 5
x ← x + 3
```
Après ces deux instructions, $x$ vaut 8.

## 3. Répétition
Une boucle permet de répéter une instruction.

```text
répéter 4 fois
  avancer de 10
```

En géométrie dynamique ou dans un environnement par blocs, une boucle évite de recopier quatre fois la même instruction.

## 4. Condition
Une condition permet de choisir une action selon une situation :
```text
si score ≥ 10
  afficher "objectif atteint"
sinon
  afficher "continuer"
```

## 5. Débogage
Déboguer consiste à chercher pourquoi un programme ne produit pas le résultat attendu.

Méthode :
1. prévoir le résultat ;
2. exécuter pas à pas ;
3. repérer la première étape différente ;
4. corriger puis tester à nouveau.

## 6. Pensée informatique
Programmer n'est pas seulement écrire du code. Il faut aussi :
- décomposer un problème ;
- reconnaître des répétitions ;
- organiser des informations ;
- tester des cas ;
- expliquer une procédure.

## Erreurs fréquentes
- Confondre la valeur d'une variable avant et après une affectation.
- Répéter une instruction une fois de trop.
- Modifier plusieurs choses à la fois lors d'un débogage.

## À retenir
Un bon algorithme est une suite d'instructions compréhensible, testable et finie. La programmation sert à rendre cette procédure exécutable.
