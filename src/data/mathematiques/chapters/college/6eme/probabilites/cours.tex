\section{Objectifs}
\begin{itemize}
\item Décrire une expérience aléatoire.
\item Comprendre qu'une probabilité est un nombre entre 0 et 1.
\item Calculer dans des situations équiprobables simples.
\item Comparer modèle et fréquences expérimentales.
\end{itemize}

\section{1. Expérience aléatoire}
Une expérience est dite aléatoire lorsque son résultat n'est pas connu à l'avance.

Lancer un dé à six faces produit six issues possibles :
\[
1,2,3,4,5,6.
\]

\section{2. Évènement}
Un évènement regroupe une ou plusieurs issues.

Exemple : « obtenir un nombre pair » correspond aux issues $2,4,6$.

\section{3. Probabilité}
Une probabilité est comprise entre 0 et 1.
\begin{itemize}
\item 0 : évènement impossible ;
\item 1 : évènement certain ;
\item entre 0 et 1 : évènement possible.
\end{itemize}

\section{4. Équiprobabilité}
Si toutes les issues sont également probables :
\[
P(A)=\frac{\text{nombre d'issues favorables}}{\text{nombre total d'issues}}.
\]

Avec un dé équilibré :
\[
P(\text{pair})=\frac36=\frac12.
\]

\section{5. Fréquence expérimentale}
Après plusieurs répétitions, on peut calculer la fréquence d'un évènement. Elle varie d'une série d'expériences à l'autre et peut être comparée à la probabilité du modèle.

Une fréquence observée n'est pas obligée d'être exactement égale à la probabilité théorique.

\section{Erreurs fréquentes}
\begin{itemize}
\item Croire qu'un évènement de probabilité 1/2 doit se produire exactement une fois sur deux dans une courte série.
\item Compter deux fois une même issue.
\item Utiliser la formule d'équiprobabilité lorsque les issues ne sont pas équiprobables.
\end{itemize}

\section{À retenir}
La probabilité appartient à $[0;1]$ et décrit un modèle du hasard. Les fréquences expérimentales permettent de confronter ce modèle à des observations.
