\section{Objectifs}
\begin{itemize}
\item Utiliser le théorème de Thalès.
\item Reconnaître une configuration de parallélisme.
\item Utiliser les rapports trigonométriques dans un triangle rectangle.
\end{itemize}

\section{1. Théorème de Thalès}
Dans une configuration où les droites correspondantes sont parallèles, les longueurs sont proportionnelles.

Si $A,M,B$ sont alignés, $A,N,C$ sont alignés et $(MN)\parallel(BC)$ :
\[
\frac{AM}{AB}=\frac{AN}{AC}=\frac{MN}{BC}.
\]

\section{2. Calculer une longueur}
Si
\[
AM=3,quad AB=5,quad AC=10,
\]
alors
\[
\frac{3}{5}=\frac{AN}{10},
\]
donc
\[
AN=6.
\]

\section{3. Réciproque}
Si les points sont alignés dans le même ordre et si les rapports correspondants sont égaux, on peut conclure au parallélisme.

\section{4. Trigonométrie}
Dans un triangle rectangle, pour un angle aigu $\alpha$ :
\[
\cos\alpha=\frac{\text{adjacent}}{\text{hypoténuse}},
\]
\[
\sin\alpha=\frac{\text{opposé}}{\text{hypoténuse}},
\]
\[
\tan\alpha=\frac{\text{opposé}}{\text{adjacent}}.
\]

\section{5. Choisir le bon rapport}
On identifie :
\begin{enumerate}
\item l'hypoténuse ;
\item le côté opposé à l'angle ;
\item le côté adjacent.
\end{enumerate}

Puis on choisit le rapport qui contient les deux grandeurs utiles.

\section{6. Calculatrice}
Pour déterminer un angle, on utilise les fonctions inverses de la calculatrice après avoir vérifié qu'elle est en degrés.

\section{Erreurs fréquentes}
\begin{itemize}
\item Appliquer Thalès sans parallélisme.
\item Mélanger des côtés non correspondants.
\item Confondre opposé et adjacent.
\item Utiliser la calculatrice en radians.
\end{itemize}

\section{À retenir}
Thalès exploite une proportionnalité géométrique ; la trigonométrie relie angles et longueurs dans un triangle rectangle.
