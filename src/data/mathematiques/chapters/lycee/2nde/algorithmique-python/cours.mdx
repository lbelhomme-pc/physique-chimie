## Objectifs

- Choisir ou déterminer le type d'une variable : entier, flottant, booléen ou chaîne de caractères.
- Écrire une affectation, une séquence d'instructions, une condition et une boucle.
- Programmer une boucle bornée `for` et une boucle non bornée `while`.
- Écrire et appeler une fonction à un ou plusieurs arguments.
- Lire, comprendre, compléter ou modifier un programme mathématique.
- Utiliser une fonction aléatoire pour simuler une expérience et répéter une expérience aléatoire.
- Lire une fonction qui calcule une moyenne ou un écart type sans exiger la maîtrise des listes.
- Passer du langage naturel à Python et contrôler systématiquement la cohérence du résultat.

## Prérequis

- calcul numérique
- lecture d'instructions simples
- notions d'algorithme vues au cycle 4

## Activité de découverte

Un programme de calcul répété à la main devient vite pénible. On le décrit d'abord en langage naturel, puis on le traduit en Python afin de tester beaucoup de valeurs et d'observer un phénomène. La comparaison entre les deux écritures aide à distinguer l'idée mathématique de sa traduction informatique.

## Cours

### Variables et affectation

Une variable informatique associe un nom à une valeur. Son type dépend de la valeur manipulée :

```python
n = 12              # entier
x = 3.5             # flottant
ok = True            # booléen
message = "seconde" # chaîne de caractères
```

L'affectation Python utilise `=`. Elle ne doit pas être confondue avec l'égalité mathématique. Une séquence d'instructions est exécutée dans l'ordre où elle est écrite.

### Conditions

Une instruction conditionnelle choisit un traitement selon une condition booléenne.

```python
if x >= 0:
    resultat = "positif ou nul"
else:
    resultat = "négatif"
```

### Boucles

Une boucle `for` est adaptée lorsque le nombre de répétitions est déterminé à l'avance. Une boucle `while` convient lorsqu'on répète jusqu'à ce qu'une condition soit satisfaite.

```python
for k in range(5):
    print(k)

n = 0
while 2**n < 1000:
    n += 1
```

Pour une boucle `while`, il faut vérifier que la condition peut devenir fausse afin d'éviter une boucle infinie.

### Fonctions

Une fonction peut recevoir un ou plusieurs arguments et renvoyer un résultat.

```python
def affine(x, m, p):
    return m*x + p
```

L'appel `affine(2, 3, 1)` renvoie `7`.

Le programme de seconde demande aussi de savoir lire ou compléter des fonctions un peu plus complexes, par exemple une fonction calculant une moyenne ou un écart type ; aucune connaissance particulière sur la structure interne des listes n'est exigée.

### Aléatoire et simulation

Une fonction aléatoire permet de produire le résultat numérique d'une expérience aléatoire. La répétition de l'appel produit une série statistique et permet d'observer la stabilisation des fréquences.

```python
from random import random

def bernoulli(p):
    return 1 if random() < p else 0

def frequence(n, p):
    succes = 0
    for _ in range(n):
        succes += bernoulli(p)
    return succes / n
```

### Lire, modifier, vérifier

Pour tout programme :

1. préciser les **entrées** et la **sortie** attendue ;
2. décrire les étapes en langage naturel ;
3. choisir des noms de variables explicites ;
4. tester sur un cas calculable à la main ;
5. vérifier les valeurs limites et la cohérence du résultat ;
6. modifier une instruction à la fois lorsqu'on cherche une erreur.

## Erreurs fréquentes

- Confondre `=` en Python et l'égalité mathématique.
- Confondre entier, flottant et chaîne de caractères.
- Écrire une boucle `while` sans mécanisme permettant son arrêt.
- Définir une fonction sans l'appeler ou oublier de renvoyer le résultat attendu.
- Croire qu'une simulation prouve une propriété mathématique : elle permet d'observer et de conjecturer, pas de démontrer.

## Formules et idées à retenir

- `for` : boucle bornée.
- `while` : boucle conditionnelle non bornée a priori.
- `def nom(arguments):` définit une fonction.
- `return` renvoie le résultat d'une fonction.
- `random()` peut être utilisé pour simuler une expérience aléatoire.

## Synthèse

L'algorithmique est transversale au programme : les programmes doivent être reliés aux fonctions, à la géométrie, aux statistiques, aux probabilités et au raisonnement. L'objectif n'est pas d'apprendre Python pour lui-même, mais de décrire une méthode, l'exécuter, la tester et interpréter le résultat mathématique.
