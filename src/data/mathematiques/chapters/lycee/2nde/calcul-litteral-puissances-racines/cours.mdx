## Cours

### Définitions

- Développer consiste à transformer un produit en somme.
- Factoriser consiste à transformer une somme en produit.
- La racine carrée de a ≥ 0 est le nombre positif dont le carré vaut a.

### Propriétés

- (a + b)^2 = a^2 + 2ab + b^2.
- (a - b)^2 = a^2 - 2ab + b^2.
- (a + b)(a - b) = a^2 - b^2.
- Pour a ≥ 0 et b ≥ 0, √(ab) = √a × √b.

### Méthodes

1. Avant de transformer, se demander le but : calculer, résoudre, comparer ou étudier un signe.
2. Pour factoriser ax + bx, repérer le facteur commun x : ax + bx = (a + b)x.
3. Pour une expression fractionnaire, commencer par préciser les valeurs interdites.

## Exemples corrigés

- (x + 3)^2 = x^2 + 6x + 9.
- 5x^2 - 10x = 5x(x - 2).
- √72 = √(36 × 2) = 6√2.

## Algorithmique en Python

### Première puissance dépassant un seuil

```python
def premiere_puissance(base, seuil):
    n = 0
    valeur = 1
    while valeur < seuil:
        n = n + 1
        valeur = valeur * base
    return n, valeur

print(premiere_puissance(2, 1000))
```

La boucle multiplie par la base jusqu'à dépasser le seuil demandé.

## Erreurs fréquentes

- Écrire à tort (a + b)^2 = a^2 + b^2.
- Oublier que √a est toujours positif.
- Transformer une expression sans tenir compte de l'objectif.
