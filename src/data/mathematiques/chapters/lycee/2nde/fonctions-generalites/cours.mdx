## Activité de découverte

La hauteur d'eau dans une cuve dépend du temps. À chaque instant, on associe une hauteur : cette dépendance se décrit par une fonction.

## Cours

### Définitions

- Une fonction associe à chaque valeur de la variable au plus une image.
- L'image de x par f se note f(x).
- La courbe d'équation y = f(x) est l'ensemble des points de coordonnées (x ; f(x)).

### Propriétés

- Un point M(x ; y) appartient à la courbe de f si et seulement si y = f(x).
- Un antécédent de k par f est une valeur x telle que f(x) = k.
- L'ensemble de définition contient les valeurs de x pour lesquelles f(x) existe.

### Méthodes

1. Pour calculer une image, remplacer x par la valeur donnée dans la formule.
2. Pour tester un point, remplacer x dans f(x) et comparer avec l'ordonnée du point.
3. Pour lire un antécédent sur un graphique, partir de l'ordonnée et rejoindre la courbe puis l'axe des abscisses.

## Exemples corrigés

- Si f(x) = 2x + 3, alors f(4) = 11.
- Le point A(2 ; 7) appartient à la courbe de f(x)=2x+3 car f(2)=7.

## Algorithmique en Python

### Une fonction Python comme programme de calcul

```python
def f(x):
    return 2*x + 3

for x in [-1, 0, 2, 4]:
    print(x, f(x))
```

La fonction Python reçoit un argument x et renvoie son image par le programme de calcul.

## Erreurs fréquentes

- Confondre f(2), qui est un nombre, et f, qui est la fonction.
- Dire qu'une courbe est une fonction.
- Lire l'image sur l'axe des abscisses au lieu de l'axe des ordonnées.
