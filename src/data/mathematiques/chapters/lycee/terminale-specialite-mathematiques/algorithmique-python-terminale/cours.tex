\section{1. Recherche de seuil}
~~~python
def seuil(u0, cible):
    n = 0
    u = u0
    while u < cible:
        u = 1.05 * u
        n += 1
    return n
~~~

\section{2. Dichotomie}
~~~python
def dichotomie(f, a, b, eps):
    while b - a > eps:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2
~~~

Le code ne remplace pas le théorème des valeurs intermédiaires : il affine un encadrement déjà justifié.

\section{3. Simulation de Bernoulli}
~~~python
from random import random

def bernoulli(p):
    return 1 if random() < p else 0
~~~

\section{4. Sommes}
~~~python
def somme_inverse_carres(n):
    s = 0
    for k in range(1, n + 1):
        s += 1 / (k * k)
    return s
~~~

\section{5. Intégration numérique}
~~~python
def rectangles(f, a, b, n):
    h = (b - a) / n
    s = 0
    for k in range(n):
        s += f(a + k * h)
    return h * s
~~~

\section{6. Validation}
Toujours contrôler :
\begin{itemize}
\item les entrées ;
\item les domaines ;
\item l'ordre de grandeur ;
\item la précision ;
\item la différence entre valeur approchée et valeur exacte.
\end{itemize}

\section{Erreurs fréquentes}
\begin{itemize}
\item Confondre simulation et preuve.
\item Oublier une condition d'arrêt.
\item Modifier la mauvaise borne dans une dichotomie.
\item Interpréter une valeur approchée comme exacte.
\end{itemize}
