\section{Objectifs}
\begin{itemize}
\item Connaître le format actuel de l'épreuve.
\item Savoir gérer quatre exercices indépendants en quatre heures.
\item Rédiger avec précision.
\item Utiliser la calculatrice sans lui déléguer le raisonnement.
\end{itemize}

\section{1. Format actuel}
L'épreuve écrite de spécialité mathématiques dure \textbf{4 heures} et la spécialité est affectée d'un \textbf{coefficient 16} au baccalauréat général.

La définition consolidée prévoit \textbf{quatre exercices indépendants}. Le sujet aborde une grande variété des contenus du programme.

\section{2. Ce qui est évalué}
La rédaction, la clarté et la précision des raisonnements comptent. Les sujets officiels invitent également à conserver les traces de recherche, même incomplètes.

\section{3. Lecture initiale}
\begin{enumerate}
\item lire rapidement les quatre exercices ;
\item repérer les questions indépendantes ;
\item commencer par les parties accessibles ;
\item marquer les questions à reprendre ;
\item garder une marge finale de vérification.
\end{enumerate}

\section{4. Rédaction}
Une réponse solide contient :
\begin{itemize}
\item la propriété utilisée ;
\item les hypothèses ;
\item le calcul ;
\item la conclusion.
\end{itemize}

\section{5. Calculatrice}
Elle peut évaluer, approcher, calculer une probabilité et contrôler un résultat. Elle ne remplace pas la justification.

\section{6. Questions indépendantes}
Si une question bloque, vérifier si la suivante fournit ou admet un résultat permettant de continuer.

\section{7. Contrôle final}
\begin{itemize}
\item signes ;
\item domaines de définition ;
\item probabilités entre 0 et 1 ;
\item unités ;
\item valeurs approchées et arrondis ;
\item conclusions.
\end{itemize}

\section{8. Entraînement}
Alterner exercices ciblés, transversaux, sujets en temps limité et sujets complets de 4 heures.

\section{Erreurs fréquentes}
\begin{itemize}
\item Passer trop longtemps sur une seule question.
\item Donner une valeur calculatrice sans justification.
\item Utiliser un théorème sans ses hypothèses.
\item Oublier une conclusion rédigée.
\end{itemize}

\section{À retenir}
Le bac évalue le programme et la méthode : sélectionner les outils, justifier, gérer le temps et communiquer proprement.
