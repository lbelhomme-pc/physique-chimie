\section{Objectifs}
\begin{itemize}
\item Étendre le calcul vectoriel à l'espace.
\item Décrire droites et plans par leurs directions.
\item Utiliser une base de l'espace.
\item Raisonner sur la position relative d'objets géométriques.
\end{itemize}

\section{1. Vecteurs de l'espace}
Les opérations sur les vecteurs du plan restent valables dans l'espace :
\[
\vec u+\vec v,\qquad \lambda\vec u.
\]

Une combinaison linéaire de $\vec u,\vec v,\vec w$ est une expression
\[
a\vec u+b\vec v+c\vec w.
\]

\section{2. Colinéarité}
Deux vecteurs non nuls sont colinéaires si l'un est un multiple de l'autre :
\[
\vec v=\lambda\vec u.
\]

Deux droites ayant des vecteurs directeurs colinéaires sont parallèles ou confondues.

\section{3. Droite de l'espace}
Une droite est déterminée par un point $A$ et un vecteur directeur non nul $\vec u$.

Un point $M$ appartient à la droite si
\[
\overrightarrow{AM}=t\vec u
\]
pour un réel $t$.

\section{4. Plan de l'espace}
Un plan est déterminé par un point $A$ et deux vecteurs non colinéaires $\vec u,\vec v$.

Un point $M$ appartient au plan si
\[
\overrightarrow{AM}=s\vec u+t\vec v
\]
pour des réels $s,t$.

\section{5. Base de l'espace}
Trois vecteurs non coplanaires forment une base de l'espace. Tout vecteur peut alors s'écrire de manière unique
\[
\vec x=a\vec u+b\vec v+c\vec w.
\]

\section{6. Positions relatives}
Deux droites de l'espace peuvent être :
\begin{itemize}
\item sécantes ;
\item parallèles ;
\item confondues ;
\item non coplanaires.
\end{itemize}

Une droite et un plan peuvent être parallèles, inclus l'un dans l'autre ou sécants.

\section{Erreurs fréquentes}
\begin{itemize}
\item Penser que deux droites non parallèles de l'espace sont forcément sécantes.
\item Confondre colinéarité de deux vecteurs et coplanarité de trois vecteurs.
\item Oublier qu'un plan nécessite deux directions non colinéaires.
\end{itemize}

\section{À retenir}
La direction d'une droite est portée par un vecteur non nul ; la direction d'un plan est engendrée par deux vecteurs non colinéaires.
