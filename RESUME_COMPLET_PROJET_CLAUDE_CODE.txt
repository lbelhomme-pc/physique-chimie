============================
  DESCRIPTION DU PROJET
============================

Plateforme éducative française de révision en physique-chimie,
ciblant les élèves du collège (6ème→3ème) et du lycée.
Modèle freemium. Accessible, gamifiée, avec accessibilité DYS.

Stack technique :
  - Framework : Astro.js (v5.18+) avec React et MDX
  - Math : KaTeX via remark-math + rehype-katex
  - Styles : CSS variables (design-system.css)
  - Déploiement : Vercel (site statique)
  - Données : localStorage (pas de backend pour l'instant)

Le site est EN LIGNE sur Vercel (URL .vercel.app).
Pas de domaine personnalisé pour l'instant.

============================
  BUGS CONNUS / RÉSOLUS
============================

RÉSOLUS :
  ✅ MDX + LaTeX : les $$ et ${} causaient "Could not parse with acorn"
    → Fix : installer remark-math + rehype-katex dans astro.config.mjs
  ✅ JSX style={{}} dans MDX : "Unexpected token"
    → Fix : utiliser style="..." (HTML standard) dans le MDX
  ✅ SVG inline dans MDX : les {} SVG sont interprétés comme du JS
    → Fix : supprimer le SVG inline, utiliser le composant React
  ✅ Quiz 1ère question sautée → hydration guard ajouté
  ✅ Daily login +5 XP à chaque page → corrigé (1x/jour)
  ✅ getStaticPaths manquant pour routes dynamiques
    → Fix : supprimer les anciens dossiers de routes dynamiques

CONNUS (non bloquants) :
  ⚠️ "Invalid hook call" dans la console React
    → Probablement versions React conflictuelles, non bloquant
  ⚠️ npm run preview montre l'ancien build si on n'a pas fait npm run build avant
    → Normal : toujours faire build avant preview
  ⚠️ Image OG (og-image.png) non encore créée
    → À faire sur Canva (1200×630px)

============================
  COMMENT AJOUTER UN NOUVEAU CHAPITRE
============================

  1. Crée le dossier :
     src/data/chapters/college/[niveau]/[matiere]/[slug]/

  2. Crée les 5 fichiers :
     - meta.json (copie un existant et modifie)
     - cours.mdx (contenu avec encadrés, formules $$...$$ )
     - exercices.json (tableau d'exercices progressifs)
     - quiz.json (10 QCM avec explications)
     - flashcards.json (cartes recto/verso)

  3. C'est tout ! Les routes dynamiques, le Dashboard, le Mega Quiz
     et le Mega Flashcards détectent automatiquement le nouveau chapitre.

  IMPORTANT pour les cours.mdx :
  - Les formules $...$ et $$...$$ fonctionnent grâce aux plugins
  - NE PAS utiliser style={{}} (JSX) → utiliser style="..." (HTML)
  - NE PAS mettre de SVG inline avec des {} → utiliser un composant React
  - Les encadrés utilisent des <div class="definition-box">, <div class="example-box">, etc.
