1. Définition et Constitution

Une lunette astronomique est modélisée par deux lentilles minces convergentes :

  • L'objectif ($L_1$) : Distance focale longue ($f'_1$). Il collecte la lumière de l'astre et forme une image intermédiaire $A_1B_1$.
  • L'oculaire ($L_2$) : Distance focale courte ($f'_2$). Il sert de "loupe" pour observer l'image $A_1B_1$.

2. La condition d'Afocalisme

Un système est afocal s'il donne d'un objet situé à l'infini, une image située à l'infini.

Pour cela, l'image intermédiaire $A_1B_1$ doit se former exactement dans le plan focal objet de l'oculaire.
Il faut donc confondre le foyer image de l'objectif ($F'_1$) avec le foyer objet de l'oculaire ($F_2$). La distance entre les lentilles est :
$\overline{O_1O_2} = f'_1 + f'_2$

Avantage : L'œil de l'observateur n'a pas besoin d'accommoder pour regarder l'image à l'infini, ce qui évite la fatigue visuelle.

Calcul du Grossissement $G$

Le grossissement compare l'angle sous lequel on voit l'image ($\theta'$) à l'angle sous lequel on voit l'objet à l'œil nu ($\theta$).

$G = \frac{\theta'}{\theta}$

Démonstration (avec l'approximation des petits angles $\tan \alpha \approx \alpha$) :

  1. Dans le triangle $O_1A_1B_1$ rectangle en $A_1$ :
    $\theta \approx \tan(\theta) = \frac{A_1B_1}{O_1A_1} = \frac{A_1B_1}{f'_1}$
  2. Dans le triangle $O_2A_1B_1$ rectangle en $A_1$ :
    $\theta' \approx \tan(\theta') = \frac{A_1B_1}{O_2A_1} = \frac{A_1B_1}{f'_2}$
  3. On fait le rapport : $G = \frac{A_1B_1 / f'_2}{A_1B_1 / f'_1}$
On obtient la formule finale : $G = \frac{f'_1}{f'_2}$
